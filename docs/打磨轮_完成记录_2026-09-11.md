## 二、四组改动明细

### ① 补漏检维度

| 改动 | 文件 |
|---|---|
| 新增三个段落级维度字段 `body_alignment` / `first_line_indent_in` / `space_after_pt`，各风格典型值集中在 `_BODY_LAYOUT` 表（单一真相） | `src/engine/specs.py` |
| 问卷 schema、`PAGE_KEYS`、AI 填表模板 JSON 全链路同步 | `src/engine/questionnaire.py`、`src/data/ai_questionnaire_template.json` |
| 检查层新增 4 条：正文对齐 / 首行缩进 / 段后间距 / **参考文献悬挂缩进**；容差常量独立；spec 来源页面维度仍降级 info，引用维度硬判 | `src/engine/checker.py` |
| 学校模板通道带上段落级排版（页面以学校为准的核心价值） | `src/engine/questionnaire.py` |
| 修正层新增对齐 / 首行缩进 / 段后间距三类修正 | `src/engine/fixer.py` |

关键设计：**首行缩进只作用于正文段落**（跳过标题与参考文献），避免破坏参考文献悬挂缩进。

### ② 修修正器风险

- **标题保护**：字体 / 字号 / 行距 / 对齐 / 缩进 / 段距一律跳过标题段（`is_heading` 单一判定），不再把标题压成正文 12pt；同时不再设 `Normal` 样式字号（避免未显式设字号的标题从 Normal 继承而变小）。
- **输出不覆盖**：新增 `unique_output_path()`，默认输出已存在时自动追加 `-2` / `-3`；CLI 与 GUI 共用。
- **预览升级**：`preview_fix()` 改为「现状 → 目标」diff，**只列实际会变的项**（已合规的不再出现），读不到实测值时标注「将设为」。

### ③ 准确度加固

- **表格文字纳入采样**：遍历 `doc.tables` 单元格段落，按 `tc` 元素去重（合并单元格不重复计数），字体/字号/行距统计更贴近真实；新增 `table_paragraph_count` 记录。
- **参考文献段识别统一**：抽出唯一实现 `find_reference_section()`，`read_docx` 与 `reference_paragraph_indices` 共用（消除两份重复逻辑）；并加「后随条目」佐证校验——正文里出现 "See the References section for details." 这类字样不再误判成参考文献段。
- **行距只统计正文段落**（排除标题/参考文献，避免带偏众数）。
- **缺省语义按 Word 规范补齐**：三级回退都取不到时，对齐按「左对齐」、缩进按 0、段后按 0 计入，避免对绝大多数正常文档误报「未能读取」。

### ④ 体验与工程

- CLI：`check` / `fix` 新增 `--json` 结构化输出（含 `meta / summary / resolution / conflicts / findings / profile`）。
- GUI：新增「保存报告」按钮；修正时可选输出路径（默认 `原名_fixed.docx`，走防覆盖）；问卷布尔字段改勾选框、数值字段加格式校验与常见范围提示（越界仅提示不阻止）。

## 三、顺手抓到的两个真 bug（端到端才暴露）

| bug | 现象 | 修复 |
|---|---|---|
| **Windows 控制台崩溃** | 中文 Windows 终端默认 GBK，报告里的 ✅/❌/⚠️ 触发 `UnicodeEncodeError`，`check` 命令**直接崩** | `main._init_console()`：交互终端保持原编码 + `errors="replace"`（不崩）；**管道/重定向强制 UTF-8**（外部程序可解析） |
| **--json 被降级成问号** | 若沿用终端编码，JSON 里的中文/箭头会被替换成 `?`，机器无法解析 | JSON 一律经 `_write_json()` 走 UTF-8 **字节流**输出，绕开编码降级 |
