# PaperFormat Pro · 排版能力边界说明（APA 7th + MLA 9th，中文版）

> 适用对象：使用「文档格式先生 · 海外版 PaperFormat Pro」的 APA 7th 学生版 / 专业版用户、MLA 9th 用户（学生课程作业 / 毕业论文），以及我们自己的产品 / 运营 / 客服团队。
> 文档定位：把「我们能做、不能做、你必须看什么、你必须自己做什么」一次说清，避免海外客户误以为这是「一键交稿 / 自动评分」工具。

---

## 0. 一句话定位

PaperFormat Pro 是一款**离线、零网络、零大模型**的**排版格式助手**：它帮你把文档的**版式格式**（页边距、行距、对齐、缩进、字体、标题层级、参考文献排版等）核对并自动修正到所选引用风格（如 APA 7th）的规范；它**不碰、不重写你的正文内容**，也**不对引文内容的对错负责**。

它不是查重工具、不是语法校对工具、不是自动评分系统，更不是「一键替你交稿」的按钮。

---

## 1. 我们能做什么（排版 / 版式层，已商用级覆盖并验证）

以下能力已写进规则引擎、有回归测试兜底，并在 APA 官方标注样例（`student-paper-annotated.docx` / `professional-paper-annotated.docx`）上**零误报**验证通过。

### 1.1 页面与正文排版（APA 7th）
| 维度 | APA 7th 规范 | 我们的处理 |
|---|---|---|
| 页边距 | 四边均为 1″（§2.14） | 检查（作为典型值提示，不强制 fail） |
| 行距 | 双倍行距（§2.21） | 检查 + 可自动修正 |
| 正文对齐 | **左对齐，禁止两端对齐**（§2.22） | 检查（APA 下为 **warn** 级）+ 可自动修正 |
| 首行缩进 | 每段首行缩进 **0.5″**（§2.24） | 检查（APA 下为 **warn** 级）+ 可自动修正 |
| 正文字体 | 6 款无障碍字体：Times New Roman / Calibri / Arial / Georgia / Lucida Sans Unicode / Computer Modern（§2.19） | 检查（字体不在清单内提示） |
| 正文字号 | 典型 12pt（11pt 对应 Calibri/Arial/Georgia，10pt 对应 Lucida Sans Unicode/Computer Modern） | 检查（作为典型值提示） |

> 说明：页边距 / 字号 / 行距这类「页面级」数值，遵循**模板驱动铁律**——只有学校模板或格式问卷显式给出时才硬判；默认只作典型值参考并提示，不会随便判你 fail。

### 1.2 标题层级（5 级，APA 7th §2.26–2.27）
| 级别 | 格式 |
|---|---|
| L1 | 居中、加粗、标题大小写 |
| L2 | 左对齐、加粗、标题大小写 |
| L3 | 左对齐、加粗斜体、标题大小写 |
| L4 | 缩进、加粗、标题大小写、**以句号结尾（run-in 段内标题）** |
| L5 | 缩进、加粗斜体、标题大小写、**以句号结尾（run-in 段内标题）** |

- 检查（APA 下为 **warn** 级：标题层级格式不对会明确提示）+ 可自动按 5 级规则落盘。
- 修复后已用回归测试**逐层读回直写格式验证**（L1 居中加粗、L2 左对齐加粗、L3 左对齐加粗斜体、L4 缩进加粗句号、L5 缩进加粗斜体句号全部命中）。

### 1.3 参考文献排版（References）
| 维度 | 规范 | 我们的处理 |
|---|---|---|
| 标题格式 | 「References」**加粗 + 居中 + 另起一页**（§2.9 / §9.2 / §2.17） | 检查（用了标题样式→判为通过并信任样式；手写的没加粗/没居中→提示） |
| 悬挂缩进 | 每条 0.5″ 悬挂缩进（§9.43–9.44） | 检查 + 可自动修正 |
| 排序 | 按首作者姓氏字母序（§9.44） | 检查（**info** 提示，不强制） |
| 期刊名 / 书名 | 应为斜体（§6.22 / §10.1） | **info** 稳健提示（整份无斜体时才提示，不会误伤官方样例） |
| 作者连接符 | 末两位作者之间用「&」（§9.7） | **info** 稳健提示（只在作者段出现「, and 」时提示，不误伤书名里的 and） |

> 为什么期刊斜体 / & 连接符只给 info、只做宏观提示？因为这两项是**内容语义**判断（哪些词是期刊名、哪段是作者），官方标注样例本身也有「无 DOI、缺期号」的合法条目。我们刻意只在大尺度可疑信号出现时给 info，**绝不武断改写你的文献内容**，也绝不因此误报金标准论文。

### 1.4 前置材料（学生版 / 专业版差异见第 4 节）
- 标题页结构检查（标题 / 作者 / 单位 / 课程 / 教师 / 日期等）。
- 专业版：running head（页眉短标题 + 页码）、Abstract + Keywords、作者注（author note）、running head ≤ 50 字符（§2.8）。
- 块引用（block quotation）0.5″ 缩进（§8.25–8.27）。

## 2. 我们不能做什么（引文内容 / 语法层，明确不在范围内）

以下内容属于「**正文内容**」，依据产品铁律**绝不自动改写**；工具不对其对错负责，也不声称能检查。请务必由你本人核对：

1. **作者-年份引文语法对错**：括号里 (Author, Year) 的写法是否规范。
2. **et al. 使用规则**：几名作者该用 et al.、该写几个名字。
3. **括号内 & 与 and 的区分**：正文括号内应用 & 而非 and（§8.11）。
4. **同作者同年 a/b/c 后缀**：重名年份的区分标记。
5. **机构作者 / 匿名作者**的处理方式（§9.11–9.12）。
6. **作者姓名大小写与倒置**：姓在前还是名缩写在前后。
7. **20 / 21 名以上作者**的省略规则（§9.8）。
8. **DOI / URL 的有无与格式**（§9.34–9.35）：官方样例本身就允许无 DOI 的条目，我们刻意不查，避免误报。
9. **文章标题句首大写（sentence case）**是否正确（§6.14 / §10.2）。
10. **期号（issue number）**的取舍（§9.31）。
11. **参考文献与正文引用是否一一对应**：有没有漏引、多引、错引。
12. **拼写、语法、学术表达、逻辑连贯性**等语言质量。

> 一句话：凡是「内容对不对、写法合不合规」的活儿，都是你自己的责任；我们只在「版式漂不漂亮、层级对不对」上出力。

## 3. 你必须看的提示（读了才不会白用）

工具跑完会生成一份 **findings 报告**，按严重度分级。**请至少读完这几类**：

- **warn（警告）级**：APA 下集中在三个维度——`alignment`（必须左对齐、不能两端对齐）、`first_line_indent`（必须 0.5″）、`heading`（5 级标题格式）。这些是你版式上最该改的地方。
- **info（提示）级**：尤其是 `Reference italics`（期刊名/书名是否斜体）、`Reference author connector`（是否该用 &）、`reference_sort`（是否字母序）、`reference_heading`（References 标题是否加粗居中）。它们不强制，但认真看能少挨导师/审稿人一顿批。
- **pass（通过）级**：说明这些项你已经做对了，无需再动。

> 技术细节：Word 的「标题样式」会把加粗/居中「藏」在样式里，工具读不到——所以如果你的 References 或各级标题用的是样式（Heading 1–5），工具会**信任样式**判为通过（pass）；若是手写直写格式，则按直写值检查。两种情况我们都不会乱改你的内容。

## 4. 两个 APA 版本的差异（你选错版本会白查）

| 项目 | 学生版（Student / 课程作业） | 专业版（Professional / 投稿发表） |
|---|---|---|
| running head（页眉短标题） | 不要求 | **要求**（≤50 字符） |
| Abstract + Keywords | 不要求（除非老师要求） | **要求** |
| 作者注（author note） | 不要求 | **要求** |
| 标题页 | 标题(粗体居中)+姓名+院系+课程号:课名+教师+日期 | 作者+单位(上标)+作者注 |
| 正文 / 参考文献规则 | **完全一致** | **完全一致** |

> 选错版本，专业版会提示你缺 running head / 摘要 / 作者注；学生版则不会。请按你学校/期刊的实际要求选。

## 5. 你必须自己做的（交稿前 checklist）

1. **核对引文内容**：每条参考文献的作者、年份、标题、来源、DOI/URL 是否真实准确。
2. **核对一一对应**：正文里的每一个 (Author, Year) 都能在 References 找到；反之 References 里的每一条都被正文引用过。
3. **按第 3 节读完所有 warn / info 提示**，该改的版式用「自动修正」或手动改掉。
4. **通读全文**：拼写、语法、表达、逻辑——这些工具不管。
5. **最终人工审核后再提交**：本工具只是助手，不对你的最终成绩 / 录用负责。

## 6. 它绝不是什么（请转告每一位客户）

- ❌ 不是「一键交稿」按钮：跑完仍需你人工核对与修正。
- ❌ 不是自动评分 / 查重系统：它不判断你写得好不好、抄没抄。
- ❌ 不是语法 / 拼写校对软件。
- ❌ 不保证你的论文「一定符合学校 100% 要求」：学校模板若与 APA 典型值有出入，请以学校模板为准，并在问卷 / 模板中显式声明。
- ✅ 是**离线、私有、可重复的排版格式检查 + 自动修正助手**。

## 8. MLA 9th 能力边界（与 APA 平行）

> MLA 9th 与 APA 7th 同为「版式格式助手」覆盖对象，但**检查严厉度不同**：MLA 的页面 / 标题维度**一律只给 info / pass，绝不 warn / fail，也绝不自动改正文**。这是 MLA 官方样例普遍「学校模板自由度高」的刻意设计——我们只当参考提示，不替你硬判。

### 8.1 MLA 查哪些（全部 info / pass 级，绝不 fail）

| 维度 | MLA 9th 规范 | 我们的处理 |
|---|---|---|
| 页边距 | 四边 1″ | 检查（info 提示，不强制） |
| 正文字体 | Times New Roman（样例常见） | 检查（字体不在清单内 info 提示） |
| 正文字号 | 12pt | 检查（info 提示） |
| 行距 | 双倍行距 | 检查 + 可自动修正（版式） |
| 正文对齐 | 左对齐 | 检查（info）+ 可自动修正 |
| 首行缩进 | 每段首行 0.5″ | 检查（info）+ 可自动修正 |
| 段后间距 | 0（段间不留空） | 检查（info）+ 可自动修正 |
| 页眉距页顶 | ½″（MLA 9th 要求页眉离页顶 0.5″） | 检查（info / pass，**2026-10-18 已补**） |
| 页码 + running head | 每页右上：你的姓氏 + 空格 + 页码 | 检查（info） |
| 首页信息块（G2） | 标题前左上：姓名 / 教授 / 课程 / 日期，双行距，约 4 行 | 检查（info） |
| 标题格式（G3） | 居中、不加粗、不斜体、不下划线 | 检查（info） |
| Works Cited 另起页（G4a） | 参考文献列于新页 | 检查（info） |
| Works Cited 标题（G4b） | "Works Cited" 居中、**不加粗**（MLA 明确禁止加粗） | 检查（info） |
| 参考文献排序 | 按作者姓氏字母序 | 检查（info） |
| 参考文献悬挂缩进 | 每条 0.5″ 悬挂缩进 | 检查 + 可自动修正 |
| 块引用（G5） | 超过 4 行的引文：左缩进 0.5″、去引号 | 检查（info） |

> 说明：相较 APA，MLA 的「对齐 / 首行缩进 / 标题」都**只给 info**（不升级为 warn），因为 MLA 官方对正文排版自由度更高，学校模板差异大，我们不替你硬判。

### 8.2 MLA 改哪些（纯版式修正，绝不碰正文内容）

修复器（fixer）只对**版式属性**落盘，绝不重写你的正文、引文、参考文献条目文本：

- 页边距、字体、字号、行距、对齐、首行缩进、段后间距
- 块引用缩进（0.5″ 左缩进、去引号）
- 参考文献悬挂缩进（0.5″）
- 标题页排版（MLA 标题 / 作者 / 单位直写格式）
- **不**施加编号标题格式：MLA `heading_levels=0`，不需要 I./1. 这类编号标题，故不会改你的章节标题层级。

### 8.3 MLA 不查哪些（引文内容，明确不在范围内）

与 APA 第 2 节一致，以下内容属于**正文内容**，依据产品铁律**绝不自动改写**；工具不对其对错负责：

1. 文中括号引文语法：(Author page) 写法是否规范。
2. et al. 使用规则。
3. 书名 / 文章名 的斜体或引号规则。
4. 出版信息顺序与著录（Author. Title. Publisher, Year.）。
5. DOI / URL 的有无与格式。
6. 标题大小写（Title Case）是否正确。
7. 参考文献与正文引用是否一一对应。
8. 拼写、语法、学术表达、逻辑连贯性等语言质量。

### 8.4 MLA 你必须看的提示

MLA 跑完生成的 findings 报告**没有 warn / fail**，全是 info / pass。请至少读完这些 info 提示：

- `running_head`（每页右上是否 姓氏 + 页码）
- `first_page_heading`（G2 首页信息块是否齐全）
- `title_format`（G3 标题是否居中、没被加粗）
- `reference_heading`（Works Cited 是否居中、没被加粗——MLA 禁止加粗）
- `reference_sort`（字母序）
- `block_quote`（G5 长引文是否缩进去引号）

它们不强制，但认真看能少挨导师 / 审稿人一顿批。
