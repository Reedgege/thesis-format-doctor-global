## 区块 A：一键修正（核心价值，优先级最高）

### 目标
用户上传 docx → 选规范/模板 → 一键导出"格式已修正"的新 docx，**正文内容逐字不变**。

### 新增模块
- `src/engine/fixer.py`：纯格式修正引擎（无 GUI/CLI 依赖，便于测试）。
- `src/main.py` 增 `fix` 子命令；`src/ui/app.py` 增"一键修正"按钮。

### 修正项（全部限格式层）
| 项 | 改什么（python-docx API） | 数据来源 |
|---|---|---|
| 页边距 | `section.page_{top,bottom,left,right}_margin` | `TargetProfile.margins` |
| 行距 | `paragraph_format.line_spacing` + `line_spacing_rule` | `TargetProfile.line_spacing` |
| 字体 | `run.font.name` / `run.font.size` | `TargetProfile.font`（三级回退反向套用） |
| 对齐 | `paragraph.alignment` | `TargetProfile.alignment` |
| 缩进 | `paragraph_format.left_indent` / `first_line_indent` | `TargetProfile.indent` |
| 标题样式 | `paragraph.style` / outline level | `TargetProfile.heading` |
| 参考文献格式 | 重排已有条目的标点/顺序/样式串 | `TargetProfile.reference_style` |

### 内容零改动——硬约束（最关键）
- fixer **只调用** `run.font.*`、`paragraph_format.*`、`paragraph.alignment`、`section` 边距、`paragraph.style` 与"参考文献字符串重格式化"；**绝不调用任何插入/删除正文文本、增删段落、增删条目的 API**。
- **边界澄清**：参考文献段落会被"重写字符串"（如补标点、调顺序），这属格式重排、是功能本意；但**条目数量不变、作者/年份/题名等核心 token 不丢失**。
- 因此"内容零改动"断言**只覆盖正文（非参考文献）段落**；参考文献段落允许格式变化，但受"条目数不变 + 核心 token 保留"约束。

### 安全与体验
- **永远不覆盖原件**：修正结果写到 `原名_fixed.docx`，原件原样保留（等价备份）。
- 可选"预览模式"：先列出"将改哪些格式项"再确认应用（建立信任，建议 v1 就做）。
- 表格单元格内的 run 也套用字体/字号（论文三线表常见）；页眉/页脚 v1 先不碰，列入后续。

### 测试断言（`tests/test_fixer.py`）
1. `test_fix_preserves_body_text`：所有正文（非参考文献）段落拼接文本 修正前 == 修正后。
2. `test_fix_applies_margins`：边距 == profile。
3. `test_fix_applies_line_spacing`：行距规则/倍数正确（含 EXACTLY/AT_LEAST 不误判）。
4. `test_fix_applies_font`：run 字体/字号生效。
5. `test_fix_reference_count_unchanged`：参考文献条目数不变（无增删）。
6. `test_fix_reference_tokens_preserved`：每条核心 token（作者/年/题名关键词）仍在。
7. `test_fix_writes_new_file_not_overwrite`：原件未被改写、新文件存在。

## 区块 C：中台授权接入（复用现有 tfd-auth）

### 目标
海外版激活/心跳**直接复用现有 Cloudflare 中台**，不另起炉灶、不抄国内版源码。

### 做法
- 新增隔离模块 `src/license/license.py`（重写，仅协议兼容，**不从国内版拷代码**）。
- 指向现有 Worker：`https://api.reedskill.com`（与国内版同一后端）。
- 中台加渠道值 `global`：后台「⑤渠道管理」插一条 `channel='global'`，**即时生效**，无需改后端代码。
- 码类型复用：`lifetime` / `weekly` / `monthly` / `times`（海外首发建议 `lifetime` 单码，对应 Shopify 一次性买断）。
- 心跳默认 3 天，仅当服务器返回 `revoked` 才锁；离线可宽限（与国内版一致）。

### 流程
首跑 → 弹激活码输入框 → 调中台校验 → 本地存机器绑定令牌（落盘加密，无代码签名但防裸奔）→ 周期心跳。

### 安全红线（与国内版一致）
- 任何密钥 / Admin Key / Cloudflare Token **绝不进代码、不进仓、不入 memory**。
- 实施时先核对 `license.py` 实际请求路径与中台现有接口（探接口带浏览器 UA 防 1010）。
- 激活只 gate"付费功能"（修正器）；**检查（check）始终免费可用**，离线也能查——守住"离线安全"卖点。

### 待老杨拍板的一个点
海外激活后**解锁范围**：是"激活后全部功能（查+改）"还是"查免费、改（一键修正）需激活"？建议后者（与国内版"免费查/付费改"一致）。

### 测试（`tests/test_license.py`，离线 mock 中台）
- `valid`（正常）/`revoked`（已退款锁定）/`expired`（时效码过期）/`trial`（未激活可查不可改）四态断言。
- 断言"未激活时 check 可用、fix 被拒"。

## 区块 B：LaTeX 模板解析（第⑤种模板来源）

### 目标
用户给 `.cls` / `.sty` / 整套 `.tex` 工程 → 抽格式要求生成 `TargetProfile` → 走与 docx 模板**完全相同**的 `build_target` 合并逻辑。现有 docx 链路一行不动。

### 新增模块
- `src/engine/latex_template.py`：`parse_latex_template(path) -> dict`（产出 partial TargetProfile）。

### 抽取映射
| LaTeX 来源 | 抽取项 | 映射到 |
|---|---|---|
| `\documentclass[options]{...}` | 字号、纸张 | `font.size` / `page.paper` |
| `geometry` 包选项 | `left/right/top/bottom` margin | `margins` |
| `setspace`：`\onehalfspacing`/`\doublespacing`/`\setstretch{}` | 行距倍数 | `line_spacing` |
| `\bibliographystyle{...}` 或 `biblatex` style | 引用样式 | `reference_style`（见映射表） |
| 字体宏包（times/fontspec 等） | 衬线/无衬线族提示 | `font.family`（尽力） |
| 标题/章节命令 | 结构提示 | `heading`（尽力） |

引用样式映射表（未知→留空，回退到规范）：`apacite/apalike→APA`，`ieeetr→IEEE`，`plain/unsrt/abbrv→（顺序编码，近 IEEE/GB）`，`authoryear→（著者-年，近 APA/Harvard）`，`acmart→ACM`，`revtex→APS`。

### 明确边界（非 bug，是设计上限，须在文档/UI 明示）
- **不跑 TeX 引擎**：只做正则/结构解析，不编译。
- **不解析自定义宏**：`\newcommand` 重定义、复杂条件分支只读字面声明，不展开。
- **覆盖率目标 = 主流 80%**：IEEEtran、apa6/apa7、article+geometry+setspace、revtex、ACM 类。奇葩自定义校模板不保证。
- 解析失败/拿不全时：缺的字段留空，由规范(spec)兜底，并提示用户"以下项未能从 LaTeX 模板识别，已按 APA/学校规范默认"。

### 测试（`tests/test_latex_template.py`）
- 喂几段典型 `.cls`/`.sty` 片段（IEEEtran 边距、apa6 字号+行距、ieeetr 引用样式），断言抽取值符合预期。
- 断言"未知 bibstyle 时不崩溃、留空回退"。
